## 1. サービス概要（※最後に書いてOK）

黒い服ばかり選びがちな自分が、洋服の色合わせを考えるためのWebサイト。
ベースの色と任意の素材感から配色を探し、黒以外の色も選ぶ参考にする。
検索ではベース色を選び、必要に応じて光沢や表面の質感を指定する。検索結果では、3色の組み合わせと、それぞれをどのくらいの面積バランスで使うかの目安を確認できる。
服の形だけでなく、色でも見た目に変化をつけたい。
家具の色選びにも使えるかもしれない。

## 7. このアプリで実現すること

### MVPで作る機能

- 最初に用意された色とファッションのカテゴリーの中から、検索するベースの色を選ぶ。
- 任意で光沢と表面の質感を選び、ベース色と合わせて検索する。
- 選んだ色を使用したカラーパターンを表示する。
- 配色パターンの3色をbase・sub・accentとして面積量を視覚的に表示する。
- 該当のカラーパターンが与える印象、雰囲気のコメントを表示する。

### 本リリースで作る機能

- お気に入りの色を登録する。
- 持っている服の色を登録する。
- 色パターンに対して自身で考えたコーデ写真を自身のみ閲覧できる様に登録できる機能（候補）
- ユーザーがカラーパターンを登録して公開できるたり公開したカラーパターンに対して他のユーザーからスターを付けれる様にすることで無難な色だったりトレンドの把握ができる機能（候補）

## 8. このアプリの懸念点とその対策


### 懸念点①

- 何が問題になりそうか：表示された色が、実際に着たい服の組み合わせにならない可能性がある。
- なぜそう思うか：色見本だけでは、服の形や素材を含めた見た目を確認できないため。
- そのために考えている対策：形の部分はブランドごとのテーマがあるため検索時にファッションのカテゴリーを選択してから色の検索ができるようにする

### 懸念点②
- 何が問題になりそうか：配色と素材感の組み合わせが増えると、登録・確認する情報が増え、検索が遅くなる可能性がある。利用人数や操作頻度が増えれば、検索回数も増える。
- なぜそう思うか：DBからの検索方法によっては時間がかかってしまう
- そのために考えている対策：懸念点１での対策で使用したファッションのカテゴリーをつけることで検索範囲を最初に絞る様なパーティショニング方法を考える
